# AARSI

*A Reflection of You*

AARSI is a luxury jewelry brand website built to showcase the brand, products, and customer policies in a clean and responsive experience.

## Pages

* **Landing Page** — Main AARSI brand website and product showcase.
* **Terms & Conditions** — Terms and conditions governing the use of the website.
* **Refund & Return Policy** — Refund, return, and product usage policies.
* **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

## Project Purpose

The website provides AARSI with an online presence where customers can explore the brand and products while having easy access to important customer policies.

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite

## Project Structure

```text
src/

```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
